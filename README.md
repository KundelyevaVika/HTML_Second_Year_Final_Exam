# Tour Agency Landing Page

A responsive single-page website for a fictional travel agency "TOUR-GUIDE", created as the
final exam project of the second-year web development course at IT STEP, 2023.

The project focuses on layout, styling and responsive design; the text content is placeholder
(Lorem ipsum).

## Features
- Fixed responsive navigation bar with a collapsible mobile menu (Bootstrap 5)
- Hero section and alternating image/text story sections
- Interactive gallery: hovering over an image reveals a second image with a description
  (pure CSS transitions)
- Features section built with CSS Grid and Font Awesome icons
- Contact form layout with custom-styled inputs, radio buttons and a dropdown
  (front-end only, no backend)
- Adaptive layout for desktop, tablet and mobile using media queries

## Technologies
HTML5, CSS3 (Flexbox, Grid, media queries, transitions), Bootstrap 5, Font Awesome

## How to run
Open `index.html` in a browser.
